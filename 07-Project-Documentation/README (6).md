# Phase 7 – Project Documentation

## Project Summary
PocketSmart AI combines FastAPI, Gemini 1.5 Flash Pro, and a Jinja2-based frontend to provide budget-aware recommendations for home interiors, events, and jewelry.

## Technologies
- Python
- FastAPI
- Gemini 1.5 Flash Pro
- HTML/CSS
- JavaScript
- Jinja2
- JWT/session management

## Key Features
- Budget-based planning
- AI recommendations
- Optional image analysis
- Authentication
- Personalized session data
- Recommendation history
- Modular architecture

## Future Scope
- More categories
- Live product/service APIs
- Price and availability comparison
- Multilingual support
- Advanced budget optimization
- More reusable planning templates
